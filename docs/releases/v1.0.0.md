The first release of NotchBar: your MacBook's notch, put to work.

## Highlights

- **Now playing** from any app, including YouTube and other browser tabs, with artwork, waves and controls.
- **Claude Code usage**: your 5-hour session and weekly limits, a working indicator, and an estimate you can match to Claude's own numbers.
- **Banners** for volume and brightness, headphones and earbuds with battery levels, meetings with Join and Snooze, and finished timers.
- **Tabs** for Home, Media, Claude, Timer, Clipboard history and Calendar.
- **Dictation**: shows when apps like Handy are listening.
- **Light on battery**: about 0.1% CPU at rest.

## Install

You need a MacBook with a notch and macOS 14 or later.

1. Download **NotchBar-v1.0.0.zip** below and open it.
2. Drag **NotchBar** into your **Applications** folder.
3. Open NotchBar. macOS will say it can't verify the app, because NotchBar isn't notarized by Apple. Click **Done**.
4. Open **System Settings › Privacy & Security**, scroll to **Security**, and click **Open Anyway** next to NotchBar. Confirm with your password.

You only need to do this once. NotchBar asks for permissions such as Calendar only when you use a feature that needs them.

Prefer to build it yourself? See [Install](https://github.com/srisanthosh/NotchBar#install) in the README.

## Good to know

- The app is built by GitHub Actions from this release's source code. To check your download, compare its SHA-256 with the `.sha256` file below: `shasum -a 256 NotchBar-v1.0.0.zip`.
- It isn't signed with an Apple Developer ID, so after each update macOS treats it as a new app. You may need to allow it again in **Privacy & Security**, and grant Accessibility again if you use **Replace System HUD**.
- Found a bug? [Report it](https://github.com/srisanthosh/NotchBar/issues/new?template=bug_report.yml).
